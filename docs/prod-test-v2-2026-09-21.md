## Root cause of the fragment problem

The panel segmenter cuts tight action crops. EVERY candidate panel in the
explicit chapters (`p024_03`, `p025_02`, `p026_04`, `p022_02`, `p028_*`)
is a fragment by video-shot standards — the plan's shot-grouping model
(several panels → one shot) exists for exactly this. Interim production
answer: use the most complete explicit source available (p024_03, 613×818
cowgirl scene: both bodies + faces + genitals) and let the composition
stage rebuild the shot.
